# Humai apps: public files

Public pages for Humai apps, served by GitHub Pages at https://minhvuonghumai-creator.github.io/

- `index.html`: list of apps.
- `<app>/index.html`: each app's landing page and privacy policy (e.g. `number-spin/`).
- `app-ads.txt` (root, added once AdMob is set up): covers every app.

No app source code lives here.
